# Pemantauan Pendangkalan Alur Pelabuhan Pulau Baai

Inovasi Daerah Bengkulu untuk kegiatan Putra dan Putri Politeknik Statistika STIS.

Website ini memadukan **simulasi konseptual** proses pengendapan pasir di alur Pelabuhan Pulau Baai dengan **pemantauan citra satelit Sentinel-2 (2019–2026)** yang diolah di Google Earth Engine.

## Isi folder

| File / folder | Isi |
|---|---|
| `index.html` | Halaman utama (Beranda, Simulasi, Data Satelit, Tentang) |
| `app.js` | Kode grafik, tabel, dan galeri |
| `simulasi.html` | Simulasi interaktif pengendapan pasir |
| `data/` | Data CSV hasil Google Earth Engine |
| `gambar/` | Citra dan grafik untuk galeri |
| `presentasi/` | File PowerPoint presentasi dan gambar setiap slide (tab tersembunyi `#presentasi`) |

## Memperbarui isi

- **Mengganti gambar:** unggah file baru ke folder `gambar/` dengan nama yang sama persis.
- **Memperbarui data:** unggah CSV baru ke folder `data/` dengan nama dan kolom yang sama. Grafik dan tabel akan mengikuti otomatis.

## Catatan

Simulasi bersifat konseptual dan indikator satelit merupakan indikator awal, bukan pengukuran kedalaman alur.
